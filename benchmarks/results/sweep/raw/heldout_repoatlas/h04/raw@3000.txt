     3	Design rules
     4	------------
     5	* One implementation: every tool calls the same core function as the matching
     6	  CLI command (``repoatlas query`` -> :func:`repoatlas.retrieval.retrieve`,
     7	  ``analyze`` -> :func:`repoatlas.analysis.analyze`, ...). :class:`AtlasTools`
     8	  holds those adapters and has no MCP SDK dependency, so it is testable and
     9	  usable in-process; :func:`build_server` only registers them with the SDK.
    10	* Small, structured answers: every response is a JSON object capped at
    11	  ``MAX_RESPONSE_CHARS`` (compact JSON, env ``REPOATLAS_MCP_MAX_CHARS``). Long
    12	  lists/maps are cut and the response is marked ``"truncated": true`` with a
    13	  ``truncation`` note naming what was cut (``kept``/``total``). A view's
    14	  ``coverage`` (method + limits) is never cut; if that alone exceeds the cap,
    15	  ``truncation.over_limit`` says so.
    16	* Errors never crash the server: they come back as
    17	  ``{"error": <code>, "message": ..., "hint": <next step>, "tool": ...}``

   128	def _map_like(d: dict) -> bool:
   129	    """A dict used as a mapping (name -> data), not a record with fixed fields.
   130	
   131	    Heuristic: at least 4 entries whose values are all dicts, all lists or all
   132	    numbers (e.g. ``env_vars``, ``affected_files``, ``churn``). Records - hops,
   133	    evidence rows, claims - mix value types or hold strings and are never cut
   134	    field by field.
   135	    """
   136	    if len(d) < 4:
   137	        return False
   138	    kinds = set()
   139	    for v in d.values():
   140	        if isinstance(v, dict):
   141	            kinds.add("dict")
   142	        elif isinstance(v, list):
   143	            kinds.add("list")
   144	        elif isinstance(v, (int, float)) and not isinstance(v, bool):
   145	            kinds.add("num")
   146	        else:
   147	            return False
